# LJT-Homepage

Personal academic homepage of **Junteng Liu**, built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template (forked from [academicpages/academicpages.github.io](https://github.com/academicpages/academicpages.github.io)).

## Site content

- `_pages/about.md` — the about/home page: biography, research interests & skills, education, research experience, publications, honors & awards, and contact information.
- `_publications/` — one Markdown file per publication, listed on the Publications page (`_pages/publications.html`).
- `_config.yml` — site-wide settings and the author profile shown in the sidebar.
- `_data/navigation.yml` — header navigation (About, Publications).

Publications are listed both on the about page and on the Publications page.
